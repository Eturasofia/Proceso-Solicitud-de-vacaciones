Chatbot "Vaqui" - Proceso de solicitud de vacaciones

-- Descripcion --
Es un chatbot que automatiza el proceso de solicitud de vacaciones de los colaboradores de una empresa.

-- Requisitos -- 
.Python 3.x
.Librerias incluidas en en python: csv. datetime

--- Archivos necesarios ---
chatbot.py
colabordores.csv
solictudes.csv
ausencias.csv

--- Uso ---
Escribir cualquier mensaje para inciar
ingresar legajo
ingresa fecha de inicio de vacaciones
ingresa fecha de fim de vacaciones
El bot informa si las vacaciones estan aprobadas, rechazadas, o pendientes.
